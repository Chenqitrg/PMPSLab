# PeriodicMPS
Gauge fixing experiment of MPS on a loop

Similar to the pure topological fact that $\bbR$ is the universal covering of a circle $S^1$, we can view uniform MPS as some extension of a MPS on a loop. However, these two systems are by no means equivalent. An MPS on a loop should contain more gauge degree of freedom compared to the one on an infinitely chain. Intuitively, only trace of a matrix products is physically meaningful on a loop. Apart from the usual gauge fixing of a uMPS, we should impose more gauge fixing condition to a loopy MPS.

This repository is an on-going numerical experiment of gauge fixing of a loopy MPS.
